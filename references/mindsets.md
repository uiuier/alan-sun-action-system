# 黄毛学与孙学：从观点到行动

按需要使用本模块；查题、记账等明确任务直接完成。这里的“黄毛学”“孙学”仅指对本场访谈的有限归纳，不宣称覆盖两位嘉宾的全部思想。依据见 [sources.md](sources.md)。

## 黄毛学：保留自主判断，采取可控行动

**访谈观点：**不因合群放弃自己经逻辑判断认可的方向；专注个人发展。同时也谈到从批评中寻找有道理的部分并改变旧认知（00:14:16、00:23:11、01:11:39、02:01:45）。

**项目操作规则：**

1. 写清“我自己想实现什么”。区分本人目标与为了得到认可而追逐的目标。
2. 把意见拆成可核验事实、个人偏好与贬低。检查事实，尊重偏好，不用侮辱衡量自己的价值；不推断批评者一定嫉妒。
3. 选择一个自己能控制的动作，限定时间、金钱和影响范围；保留拒绝、退出与调整，也尊重他人的自主选择。
4. 写一条能推翻当前判断的证据。坚持目标不等于坚持每一种方法。

**触发场景：**被嘲讽、为了合群想放弃、反复比较导致停滞、他人期待挤占自己的安排。

**最小输出：**我的目标 → 意见里可验证的部分 → 我保留的边界 → 今天一个行动。

## 孙学：理解方向，验证价值，更新方法

**访谈观点：**先升级认知与工具，拓宽信息；商业关注价值创造，选择前先采样、探图；保持 small ego，吸收新信息，并随环境变化继续学习（00:12:21、00:32:40、00:40:21—00:45:59、02:09:51—02:10:21、02:23:56、02:34:20）。

**项目操作规则：**

1. 明确目标、真实需求、规则与资源。把现状、假设和待验证事项分开。
2. 按代价采样少量候选，比较工作内容、入门条件、证据与机会成本。先设采样截止时间，避免无限搜索。
3. 用一个小实验取得新信息：写明投入上限、交付物、成功标准、复盘时间与停止条件。小实验模板是本项目的操作化设计。
4. 商业项目看帮助谁解决了什么问题，以及交付与实际反馈；学习看能否独立复做。个人体验可按本人目标评价，不强迫每项活动变现。
5. 保持 small ego：主动找反例，接受有依据的批评。工具、需求或规则改变时更新方案，记录“新证据 → 改变了什么 → 下一次验证”。

**触发场景：**职业选择、学习路线、付费工具、内容项目、赚钱探索、预算与时间分配。

**最小输出：**目标与规则 → 候选比较 → 一个小实验 → 验收与调整条件。

## 两种心法互相校正

黄毛学帮助守住自主目标与行动，孙学帮助检验判断并纠正方法。自信来自理由与可承担的行动，不能代替证据；反馈能修正方案，不必决定自我价值。

例如：有人说“这项技能没前途”。先确认自己的学习理由，再采样真实岗位与需求，交付一个小作品，依据结果决定投入。若只有贬低，继续可控行动；若出现可靠反例，调整方法或方向。最终选择由用户作出。
