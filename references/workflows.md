# 按需要执行

每次只处理用户选定的问题。可按“现状 → 一项行动 → 验证 → 调整”展开；无需同时覆盖学习、健康、职业等所有领域。模板位于技能根目录的 `assets/templates/`，可以删减字段。

## 1. 建立目标与预算

先用已知信息完成草案，只追问会改变方案的缺口：目标、期限、已完成量、可用时间、资源限制与验收标准。用户的想法是候选，明确承诺的目标才进入执行计划。

若有已连接的 Notion，只读取当前问题相关的目标与进度；记录页面来源和读取日期，核对目标是否仍有效。没有连接时用用户提供的文字或导出文件继续。仅在用户授权的范围内写回。

把已有学习或工作时间与新增项目时间分别列账。每项任务归属一个预算；一次行动可以帮助多个目标，但耗时只能记一次。预计用时与实际用时分列。若任务超过预算，缩小任务或让用户取舍。

## 2. 今天与本周

给出一个主要产出、必要步骤、预计耗时、完成证据、忙碌日的最小版本，以及调整条件。安排日期用用户所在时区。考试、制度、岗位要求等会变化的信息查当前原始来源，并标注适用日期。

学习任务依次解释概念、公式含义、代入步骤和小例子，再给一道新题或复述任务。让用户先独立作答；区分看懂、借助提示完成与独立完成。根据错误选择下一题，不用刷题数量替代掌握证据。

## 3. 记录与修订

仅记录用户报告或工具实际读取的内容。明确标记“计划／实际／估计／缺失”，未知写“未提供”，不填 0。三行日报即可启动：日期与时区、实际行动及证据、下一步。来源与来源日期可另补。

用户要求保存或明确使用持续记录系统时才落盘。指定保存目录时遵从指定；未指定且需要保存时，使用当前工作区的 `action-system/`。文件名可用 `daily/YYYY-MM-DD.md`。同日新信息追加，纠错追加“修订：原记录、正确内容、修订日期与依据”；不覆盖原记录。公开示例使用虚构数据，不带入个人档案。

## 4. 周复盘与选择

比较计划和实际，从产出、独立验证、耗时与障碍判断进展。样本不足就说明不足。找出一项最值得调整的安排；写明继续、缩小、暂停或更换，以及下次检查时间。未执行的任务不自动累计为下周欠债。

做决策时列候选、限制、可靠证据和关键未知。用预先确定的标准比较；记录选择、代价与重新考虑的触发条件。自尊与身份判断不代替事实检验。

## 5. 机会小实验

把职业或赚钱想法写成可证伪假设，限定时间、金钱和结束日期，制作可查看的样品。明确目标对象、需求证据、成功指标和停止规则。需要联系他人或对外发布时，先准备可审阅成果，并按用户授权执行。未发布、未获得真实反馈就写“待验证”；浏览量、收入或就业结果不作保证。

## 6. 健康摘要

先确认当前环境能否读取健康数据。没有可用工具时分析用户提供的摘要或导出，不宣称已接通，也不要求安装或付费。记录来源、覆盖日期、时区、单位、最后更新时间与缺失项。

多个设备的步数可能重叠，优先使用去重总量，不把来源直接相加。睡眠区分在床与睡着；体重与心率仅比较可比记录。照片只能支持大致饮食描述，不推算精确热量。提供一般活动与作息建议；不诊断、不处方、不从单次异常推断疾病。有症状或持续异常时建议咨询医护人员。
